# 生命数字密码 · 生命蓝图解析

基于苏醒《生命数字密码》（湖南文艺出版社）的数字命理（毕达哥拉斯占数学）计算与解读网站。输入出生日期，自动计算并解读各项生命密码。

> 仅供个人参考。所有解读内容均源自原书，搬运自用。

## 功能

输入「年-月-日」后，自动计算并展示：

| 项目 | 说明 |
|------|------|
| **命数（命运数）** | 出生年月日所有数字相加至个位（保留卓越数 11/22/33） |
| **天赋数** | 命数计算过程中的中间数（如 40/4），代表潜能方向 |
| **生日数** | 出生日化至个位，天性人格与行为标签 |
| **先天数 · 三阶段** | 出生月/日/年 → 型塑启蒙期 / 产出壮年期 / 丰收晚年期 |
| **限制数** | 出生月+日，童年形成的制约模式 |
| **流年数** | 当年流年 + 未来 9 年循环时间轴（可点击） |
| **频率最多数** | 生日中出现 ≥3 次的数字能量分析 |
| **生日九宫图** | 洛书九宫布局 + 8 主线 4 副线连线分析 + 空缺数 |
| **星座** | 星座对应数字 |

## 技术栈

- **前端**：原生 HTML / CSS / JavaScript（浏览器 ES Modules），无框架、无打包器
- **界面**：深色烫金神秘风，CSS 设计令牌驱动，含生成动画、流光分享卡、可点击流年时间轴
- **服务**：Node.js + Express，仅用于托管静态文件（`public/`）
- **进程**：PM2 守护
- **对外**：宝塔 Nginx 反向代理 + 域名（应用本身只监听 `127.0.0.1`）

## 本地运行

```bash
# 方式一：Node 服务（与线上一致）
npm install
node server.js            # → http://localhost:3300

# 方式二：纯静态预览（无需依赖）
cd public
python3 -m http.server 8080   # → http://localhost:8080
```

## 部署到服务器

应用由 PM2 守护，监听 `127.0.0.1:3300`，由 Nginx 反代对外。

```bash
# 初次部署：在服务器上
cd /www/wwwroot/shuzimima
npm install
pm2 start ecosystem.config.js
pm2 save                   # 开机自启

# 之后每次更新代码（本地执行）
./deploy.sh                # rsync 同步 + 按需 npm install + pm2 reload + 自检
```

Nginx 反代目标：`http://127.0.0.1:3300`。

## 运维常用

```bash
pm2 logs shuzimima         # 日志
pm2 restart shuzimima      # 重启
pm2 status                 # 状态
```
